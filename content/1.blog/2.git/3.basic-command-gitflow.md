# พื้นฐาน Command สำหรับ Git flow

## Install Git Flow
**MacOS**
````bash
brew install git-flow  
````

**Linux**
````bash
apt-get install git-flow 
````

**Windows**
````bash
wget -q -O - --no-check-certificate https://raw.github.com/petervanderdoes/gitflow-avh/develop/contrib/gitflow-installer.sh install stable | bash  
````


## พื้นฐาน Command Gitflow

โดยเริ่มแรกคำสั่งพื้นฐานในการเริ่มต้นใช้งาน git-flow extension คือ
````bash
git flow init -d
````

จะทำการสร้าง branch develop ขึ้นมาเพื่อใช้งานสำหรับนักพัฒนา สามารถตรวจสอบโดยใช้คำสั่ง
````bash
git branch
````
   *"จะเห็นได้ว่ามี branch develop เพิ่มขึ้นมาให้อัตโนมัติและมันยังบอกว่า support branch อะไรบ้างด้วย"*

### สร้าง feature branch
````bash
git flow feature start <feature_name>
````

เมื่อทำการพัฒนาเสร็จหรือต้องการ merge เข้า develop ให้ใช้คำสั่ง

````bash
git flow feature finish <feature_name>
````
จะทำการ check out ไปยัง branch develop และทำการลบ branch feature

### Release branch

เมื่อนักพัฒนาได้พัฒนามาถึงจุดที่ต้องการให้ tester ได้ทดสอบหรือลองเล่น feature ใหม่ๆที่นักพัฒนาเป็นคนพัฒนาขึ้น ก็จะออกสาขาใหม่ที่เรียกว่า release branch โดยจะใช้เลขแท็กเป็นตัวกำหนดเวอร์ชั่นให้กับ release นั้นๆ

````bash
git flow release start 0.1.0
````

เมื่อผ่านการทดสอบแล้วก็ทำการ merge to main โดยใช้คำสั่ง
````bash
git flow release finish '0.1.0'
````
โดยจะทำการ merge ไปยัง main และ develop

### Hotfix Branch

เมื่อเกิดบัคบน branch main และต้องมีการแก้ไขแบบเร่งด่วนจะต้องใช้ hotfix branch ในการแก้ไขโดยใช้คำสั่ง
````bash
git flow hotfix start <hotfix_name>
````
เมื่อแก้ไขเสร็จให้ใช้คำสั่ง
````bash
git flow hotfix finish <hotfix_name>
````
จะทำการ merge ไปยัง branch main ให้อัตโนมัติ
