# Git คืออะไร?

Git คือ **Version Con​​trol** หรือเครื่องมือที่จะช่วยจัดการเวอร์ชั่นของโค้ด สามารถติดตามการเปลี่ยนแปลงเพิ่มลบหรือแก้ไขของไฟล์ได้และยังสามารถย้อนกลับไปยัง Version ต่างๆ ตามที่ต้องการได้อีกด้วย เป็นเครื่องมือที่สำคัญสำหรับ Developer เลยก็ว่าได้

## ทำความเข้าใจ Git กันเต๊อะ

วันนี้จะมาอธิบาย Git แบบง่ายๆ อะไรบ้างที่จำเป็นและสิ่งสำคัญที่ต้องรู้เกี่ยวกับ Git บ้าง เพราะเอาเข้าจริง Git ไม่ได้ยากอย่างที่คิดแค่ต้องใช้เวลาปรับตัวและทำการเข้าใจมันสักนิดนึ่ง

- 1. **Git Branch** โดยการทำงานของ Git จะแยกเป็นแต่ละสาขา โดยแต่ละสาขาจะมีการทำงานหรือหน้าที่ที่แตกต่างกันออกไปตามความต้องการของแต่ละนักพัฒนา โดยส่วนมากจะมี  *Branch* หลักที่ชื่อว่า main หรือ master <ins>(ขึ้นอยู่กับผู้ใช้งาน)</ins> จะคอยทำหน้าที่เป็นสาขาหลักในการควบคุมเวอร์ชั่นของโค้ด
- 2. **Check out Branch** หรือการเปลี่ยนสาขานั่นเอง เมื่อเราทำการพัฒนาเราจะแยกสาขาออกมาเพื่อไม่รบกวนสาขาหลักนั่นเอง โดยแต่ละสาขาที่แยกออกมาก็จะทำการพัฒนาตามหน้าที่ของ Branch นั้นเมื่อพัฒนาเสร็จก็รวมมายัง Branch หลักเพื่อเป็นการรวม *Sourch code*
- 3. **Conflict** คือการชนกันหรือการขัดแย้งภายใน *Sourch code* เมื่อเกิด *Conflict* เมื่อเราทำการรันโปรแกรมจะเกิด *ERROR* ให้ทำการแก้ *Conflict* ก่อนโดยการแก้นั้นแค่เลือกว่าจะเอา Sourch code ของส่วนไหนแค่นี้ก็ทำการแก้ไขได้แล้ว

## พื้นฐาน Command Git

- 1. **Git Clone** ไว้สำหรับดาวน์โหลด sourch code บน remote repository
````shell
git clone <https://name-of-the-repository-link>
````
- 2. **Git status** คือการแสดงไฟล์ที่มีการเปลี่ยนแปลง และสามารถแสดง state ของไฟล์ได้ด้วย
````shell
git status
````
- 3. **Git add** คือการเพิ่มไฟล์เป็นสถานะ stage
````shell
git add <file>
git add -A or git add .
````
- 4. **Git commit** คือการ commit ไฟล์ที่อยู่ใน stage
````shell
git commit -m "commit message"
````
- 5. **Git push** คือ ส่งการเปลี่ยนแปลงของไฟล์ไปบน remote repository มายัง local repository
````shell
git push <remote> <branch-name>
````
- 6. **Git fetch** คือ การตรวจสอบไฟล์ภายใน local และ remote ว่าตรงกันหรือไม่
````shell
git fetch
````
- 7. **Git pull** คือการ remote ไฟล์มายัง local โดยคำสั่ง git pull นั้นจะทำการ git fetch และ git merge ไปด้วย
````shell
git pull <remote>
````
- 8. **Git Checkout** คือการเปลี่ยน branch ไปยัง branch ที่ต้องการ
````shell
git checkout <name-of-your-branch>
````

## สรุป
