# Tags ต่างๆมีประโยชน์อย่างไรในการทำ SEO
**Tags** ต่างๆในส่วนหัวหน้าเว็บไซต์ของ **HTML** เรามีประโยชน์อย่างไรทุกคนที่กำลังศึกษาด้านเว็บไซต์คงกำลังเกิดประเด็นสงสัยในเรื่องนี้ โดยวันนี้ผมจะมาอธิบายและบรรยายให้ฟังว่า *Tags* ในแต่ละอันมีหน้าที่อะไรแล้วเราใส่ไปทำไม *Tags* นั้นจำแนกได้เป็นหลายประเภทมากโดยแต่ละ *Tags* ก็ทำหน้าที่แตกต่างกันไปในการทำ **SEO** แล้ว *Tags*  พวกนี้มีความสำคัญมาก โดยหลักของ **Search Engine** แล้ว *Tags* พวกนี้จะเป็นตัวบอกว่าเว็บไซต์ของเรามีหัวข้อและเนื้อหาตรงกับความต้องการของผู้ค้นหามากน้อยแค่ไหน เมื่อคำนวณจากปัจจัยหลายๆอย่างของหน้าเว็บเรา(ไม่ใช่แค่Tags) Search Engine ของ Google จะแสดง **SERP(Search Engine Results Page)** หน้าผลลัพธ์การค้นหาเรียงจากคำต้องการของผู้ค้นหามากที่สุดลงมา

## Title Tags
เป็นตัวแสดงผลหัวข้อหรือชื่อเพจด้านบนสุดของเว็บเบราว์เซอร์ และแสดงผลบน *Headline* ของ *Search Engine Results Page* **Title Tags** จะเป็นตัวบอกกับผู้ค้นหาว่าเว็บมีเนื้อหาเกี่ยวกับอะไรบ้างและเกี่ยวข้องกับสิ่งที่ผู้ค้นหากำลังค้นหาอยู่หรือไม่ รวมทั้งเป็นตัวตัดสินใจว่าจะกดเข้ามายังเว็บไซต์นี้หรือไม่ โดย *Title Tags* มีความสำคัญมากควรเลือกความหมายที่ดีและเป็นที่ต้องการของคนส่วนมาก

## Description Tags
เป็นรายระเอียดโดยย่อของเนื้อหาทั้งหมดของเว็บไซต์โดยจะแสดงผลในหน้า *Search Engine Results Page* เป็นรายละเอียดข้างล่าง *Title Tags* โดยทั่วไปแล้ว *Description Tags* ควรอธิบายข้อมูลที่เป็นประโยชน์หรือรายละเอียดสรุปของเนื้อหาหน้าเว็บไซต์นั้น เพื่อที่จะดึงดูดผู้ค้นหาให้เข้ามายังเว็บไซต์ คุณจะต้องสรุปให้ได้ใจความสำคัญที่สุดและมีข้อมูล *Keyword* สำคัญที่เมื่อลูกค้าเห็นเข้าใจทันที

## Viewpoint Tags
เป็น *Tags* ที่จะมาช่วยให้เว็บไซต์สามารถแสดงผลกับอุปกรณ์อื่นนอกเหนือจาก **Desktop** ได้เพราะอย่างที่ทราบกันว่าปัจจุบัน *Google* ให้ความสำคัญกับอุปกรณ์ **Smartphone** มากเพราะตั้งแต่ปี 2015 *Google* ได้เปิดเภยข้อมูลว่าการค้นหาจาก *Smartphone* เพิ่มสูงขึ้นต่อเนื่องโดยมียอดการค้นหามากกว่า *Desktop* ถึง 2 เท่าแล้ว หน้าเว็บไซต์ที่ดีควรรองรับอุปกรณ์ได้หลากหลาย อย่างเช่น Smartphone, Ipad, Laptop, Desktop เป็นต้น โดยหลักอาจจะไม่เกี่ยวข้องกับเนื้อหาข้อมูลภายในเว็บไซต์แต่มีผลต่อการแสดงผลกับหน้าจอหลายขนาดได้ จึงเป็น *Tags* ที่สำคัญมาก

## ALT Text Tags
หรือเรียกเต็มๆว่า **Alternative Text Tags** เป็น *Tags* ที่สำคัญอันหนึ่งเมื่อเว็บไซต์ของคุณมีรูปภาพ *ALT Text Tag* นี้จะเป็นตัวอธิบายเกี่ยวกับรูปภาพของคุณโดยอาจจะเป็น *Keyword* สั้นๆที่สื่อความหมายภาพได้ชัดเจน โดย *Tags* นี้มีความสำคัญก็คือเวลาที่ผู้ค้นหาได้ทำการ *Search* รูปภาพบน *Search Engine* จะทำให้มีโอกาสที่ผู้ค้นหาจะเจอรูปภาพที่อยู่บนเว็บไซต์เราและเพิ่มโอกาศในการค้นหาเจอได้ง่ายขึ้น

## Social Media Tags
เป็น *Tags* สำหรับโปรโมตลิ้งค์หรือเว็บไซต์เราผ่านโซเซียลมีเดียต่างๆอย่างเช่น เฟซบุ๊ค ทวิตเตอร์ เป็นต้น โดยช่วยสร้างความน่าเชื่อถือและเพื่อ **Traffic** ให้กับเว็บไซต์ของเราได้

## Header Tags
เป็น *Tags* ที่จะสร้างหัวข้อหลักหัวข้อรองภายในเว็บไซต์เป็น *Tags* ที่มีความเกี่ยวข้องในการทำ **On site SEO** ซึ่งจะเรียงลำดับจากหัวข้อใหญ่สุดไปหาเล็กสุดได้ดังนี้ H1 H2 H3 H4 H5 และ H6

## Canonical Tags
เป็น *Tags* ที่เอาไว้บอก *Search Engine* ให้รู้ว่า **URL** ที่อยู่ใน **Tags Conten** นี้คือหน้าหลักของเว็บไซต์เพื่อช่วยป้องกันการเกิดข้อมูลซ้ำได้ อาจจะเกิดปัญหาตอนที่เว็บไซต์เรามีข้อมูลที่ซ้ำกันเยอะๆ ทำให้ *Search Engine* ให้คะแนนเว็บไซต์เราลดลงทำให้การติดอันดับแรกๆในการค้นหาเป็นไปได้ยาก โดยการใส่ *Canonical Tags* ก็เหมือนกับเป็นการบอกว่าให้ Search Engine มาวัดคะแนนที่ลิ้งค์นี้
````HTML
<link href="https://example.com" rel="canonical">
````

## สรุป
*Tags* ต่างๆที่กล่าวมาข้างต้นนี้เป็น *Tags* ที่มีความสำคัญต่อการทำ **SEO** เป็นอย่างมาก โดยอาจจะมีบาง *Tags* ที่ไม่ได้พูดถึงในที่นี้อีกเยอะแยะ *Tags* เป็นแค่ส่วนประกอบหนึ่งในการทำ *SEO* แต่มันสามารถสร้าง **Traffic** ให้กับเว็บไซต์เราได้ ทำให้เว็บไซต์สามารถไต่อันดับ **Ranking** ได้อย่างรวดเร็วและในไม่ช้าก็สามารถติด 1-10 ของ *SERP* ได้ โดย *Traffic* เป็นส่วนสำคัญมากในการช่วยให้เว็บเราสามารถติดดับได้เพราะมันจะแสดงถึงประสิทธิภาพและความต้องการจากผู้ค้นหาว่าเว็บเราตอบสนองกับความต้องการของผู้ใช้งานมากน้อยแค่ไหน โดย **Google** ให้ความสำคัญกับเรื่องนี้เป็นอันดับแรก ถึงตรงนี้นักพัฒนาหรือผู้อ่านบทความนี้คงรู้ถึงความสำคัญของ Tags ต่างๆแล้วหวังว่าจะเป็นประโยชน์ไม่มากก็น้อยให้แก่ทุกคนครับ :pray::pray::pray:
